# Тринадцать моделей финального пайплайна

Всё, что входит в отправленный файл `reference/e0303_arch4_cal.csv`: 13 обученных моделей,
сведённых в три слота, плюс аффинная калибровка. Ниже — по каждой модели конфиг, точная
команда, ресурсы и измеренные числа. Ничего сверх этого списка в сабмит не входит.

**CV** — 5-fold на замороженных фолдах `data/folds.parquet` (RMSLE, ниже лучше).
**LB** — публичный лидерборд, если модель отправлялась отдельно. Напрямую они не сравнимы:
между ними стабильный зазор ≈ 0.109, измеренный по всем отправкам.

## Слот 1 — GBDT, вес 0.20

Табличная половина: признаки, построенные из разреженной панели, в градиентный бустинг.

| # | id | что это | конфиг | CV | LB solo |
|---|---|---|---|---|---|
| 1 | `e0266` | LightGBM, параметры из Optuna-поиска `e0093`, **3 сида**, усреднение в лог-пространстве, 665 признаков | `configs/e0260_regime.yaml`, арм `e0266` | **1.76441** ± 0.0216 | 1.650086 |
| 2 | `e0064` | AutoGluon `WeightedEnsemble_L2_FULL` (LightGBMXT + LightGBM + RF) на 400 отфильтрованных признаках | `configs/e0060_filt_top400.yaml` + `configs/whitelist_top400.json` | 1.76901 (4 фолда) | 1.6559 |

```bash
bash run.sh gbdt          # оба компонента целиком

# или по отдельности:
python src/run_regime.py    --config configs/e0260_regime.yaml            # CV + OOF всех конфигураций
python src/predict_seeds.py --config configs/e0260_regime.yaml --arm e0266 --out e0266
python src/run_ag.py --config configs/e0060_filt_top400.yaml --exp-id e0064 --mode full \
    --presets medium_quality --time-limit 9000 --cache
```

Ресурсы: CPU, 16 ядер, 250–300 ГБ RAM. `e0266` — 468 мин на CV (три сида × 1162 раунда ×
5 фолдов); `e0064` — 2.5 ч под лимитом AutoGluon. GPU не нужен ни там, ни там.

**Почему два компонента, а не лучший одиночный.** Сочетание `e0266 + e0064` выиграло у `e0266`
в одиночку 5/5 фолдов, включая последний — самый похожий на тест; у `e0266` в одиночку
был отрицательный фолд. При этом `e0266` на LB лучше `e0090` на 0.005, но 92 % этой разницы дала калибровка
и лишь 8 % — сама модель.

## Слот 3 — user-split рекуррентные модели, вес 0.42

Самый тяжёлый слот по весу. От слота 2 отличается **протоколом**, а не архитектурой:
разбиение здесь по `user_id` (детерминированный md5 с солью `gmv-v1`, 5 непересекающихся
фолдов), а не по якорной дате. Это позволяет обучаться на календаре вплоть до 2026-01-14 и
при этом честно валидироваться на невиданных пользователях.

Признаки: 85 каналов без календарных (`--variant full`). Календарные проверялись отдельно
(`e0142`) и **проиграли**: они переносят февраль 2025 — самый низкий по GMV участок ряда — на
февральский якорь теста. Лучший user-split CV дал худший LB из всей серии.

| # | id | архитектура | LB solo |
|---|---|---|---|
| 10 | `e0141` | GRU, hidden 128, 3 сида, вся выборка | 1.6488 |
| 11 | `e0295_usercv48` | GRU, **hidden 48**, 3 сида × 32 эпохи | — |
| 12 | `e0340_lstm48` | LSTM, hidden 48 | — |
| 13 | `e0341_xf48` | причинный трансформер, hidden 48 | — |

```bash
bash run.sh usercv        # все четыре
```

## Сборка: слоты → сабмит

```
prediction = expm1( a · [ 0.20·log1p(gbdt) + 0.38·log1p(seq) + 0.42·log1p(usercv) ] + b )
             a = 1.0328948154022706   b = -0.17536170182531663
```

Внутри слота компоненты усредняются равными весами, тоже в лог-пространстве: оптимальный точечный
прогноз для RMSLE — `E[log1p(y)|x]`, а усреднение сырых предсказаний оценивало бы `log1p(E[y])`.

```bash
bash run.sh quick    # из reference/ -> бит-в-бит с отправленным
bash run.sh blend    # из ваших subs/ после обучения
```

**Веса `0.20 / 0.38 / 0.42` подобраны один раз на OOF и больше не пересчитывались.** Три
попытки перевзвесить по CV/OOF проиграли на лидерборде (`e0270` −0.00010, `e0302` −0.00026,
`e0303` — две последние с инверсией знака относительно прогноза CV), а две замены
*содержимого* слота при неизменных весах спрогнозировались с точностью 1e-6 и 2e-6. При
корреляции компонентов 0.998 подгонка весов извлекает шум CV, а не сигнал; leave-one-fold-out от
этого не защищает — он контролирует дисперсию подгонки и слеп к сдвигу ранжирования CV→LB.

**Провенанс `a` и `b`.** Масштаб `a = ρ · sd_L / sd_M`, где `sd_L = 2.3178` решено в закрытом
виде из двух probe-сабмитов (все нули → `RMSLE² = E[L²]`; константа 10 → `RMSLE² = E[L²] −
2c·E[L] + c²`), а `ρ` — из измеренного LB. Сдвиг `b` доводит среднее до `E[L] = 2.3303`.
Обратный пересчёт из записанного `a` даёт ρ = 0.70351 против решённого из LB 0.703834.
